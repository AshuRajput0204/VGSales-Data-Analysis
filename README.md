🎮 VGSales Data Analysis

📌 Project Overview

This project analyzes global video game sales data to identify trends and understand the performance of games across different years, platforms, genres, publishers, and regions.

The project combines Python, Pandas, and Power BI to perform data analysis and create an interactive dashboard.

---

🛠️ Tools & Technologies

- 🐍 Python
- 🐼 Pandas
- 📊 Power BI
- 📓 Jupyter Notebook
- 📈 Data Visualization

---

📊 Power BI Dashboard

The dashboard provides an overview of global video game sales performance, including:

- Total Games
- Total Global Sales
- Total Platforms
- Total Publishers
- Average Global Sales
- Global Sales Trend
- Top Platforms by Global Sales
- Top Genres by Global Sales
- Regional Sales Distribution
- Top Publishers by Global Sales

🔍 Key Insights

- 🎮 The dataset contains approximately 11.4K games.
- 💰 Total global sales are approximately 8.82 billion units.
- 🎯 There are 31 distinct platforms and 577 publishers.
- 📈 2008 recorded the highest global game sales in the dataset.
- 🕹️ PS2 is the leading platform by global sales.
- ⚔️ Action is the highest-selling genre.
- 🏢 Nintendo is the top publisher by global sales.
- 🌎 North America contributes the largest share of global sales.
- 📉 Global game sales declined significantly after the peak period.
